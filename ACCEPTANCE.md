# Acceptance Criteria

The system is accepted only when:

- Customer can scan a table QR and obtain a secure table session.
- Customer can authenticate with mobile number and OTP.
- Customer cannot discover internal table IDs.
- Customer cannot access another customer's data.
- Customer can browse and search menu items.
- Customer can add items to cart.
- Server calculates authoritative order totals.
- Customer can select UPI or cash at counter.
- Orders appear in the admin dashboard.
- Admin can see required customer/order information.
- Admin can update order status.
- Admin can verify cash payments.
- UPI is never falsely marked paid.
- Admin can manage tables and QR tokens.
- Admin can manage menu items.
- Historical prices remain immutable.
- Critical security tests pass.
- Responsive UI works on customer mobile and admin desktop.
