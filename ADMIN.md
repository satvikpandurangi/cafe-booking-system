# Admin Requirements

## Dashboard
Show:
- Today's orders.
- Pending orders.
- Preparing orders.
- Completed orders.
- Today's sales.
- Pending payments.

## Orders
Show:
- Public order number.
- Customer phone.
- Authorized table information.
- Items and quantities.
- Total.
- Payment method/status.
- Order status.
- Time.

## Filters
- Date/date range.
- Status.
- Payment status.
- Payment method.
- Table.
- Phone.

## Menu
Admin can create, edit, deactivate, price, categorize, and upload images for menu items.

Historical orders retain their original item names and prices.

## Reports
- Revenue.
- Order count.
- Average order value.
- UPI/cash totals.
- Pending payments.
- Most ordered dishes.
- Daily order trends.
